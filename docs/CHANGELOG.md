# 更新记录

## 0.3.1 — 2026-10-24（测试版）

- 保留 110°–140°连续 3 秒进入、范围外连续 3 秒退出及上半屏切换动画。
- 手动打开应用也优先复用现有任务，退出时尝试移回物理屏幕。
- 去掉临时显示区移除时销毁内容的标志，避免主动结束目标任务。
- 自动承接失败时不再重发桌面启动 Intent。
- 尝试读取切换前后的媒体或原生进度，恢复明显倒退的位置。
- 打开应用时恢复此前已开启的自动监测服务。
- **已知未解决：Find N2 上抖音在切换后仍会从头播放；进度恢复不保证生效。**
