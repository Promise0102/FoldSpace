# 更新记录

## 0.6.3 — 2026-10-26（预发布）

- 展开、收起或退出时改为尝试将承载应用放回主屏任务栈底部，退出路径不再调用置前的 am display move-stack，也不在主屏注入进度恢复触摸。
- 使用临时后台任务容器和单次有序事务完成跨显示区归还；仅清理确认没有子任务的临时容器，不注册或替换系统任务组织器。
- 上下区释放完成后再结束方向页、移除悬停窗口，增加退出期间重入保护；系统接口失败时记录回退结果。
- 将双开／游戏页右下角浮动“⋯”改为贴右边缘竖向手柄，展开为可滚动侧边栏，保留液态玻璃与滑入动画。
- 新增 50 项后台归还顺序和非破坏清理断言，九组共 4776 项断言通过。当前未连接手机，后台与侧栏实际行为仍待真机确认。

## 0.6.2 — 2026-10-26（本地修正版）

- 包含 0.6.1 的普通点击单开修正；历史 dual 设置不再影响普通点击或自动悬停。
- 针对悬停横屏键无效，去掉对悬浮窗 LayoutParams 的方向设置，改用阅读器常用的 Activity.setRequestedOrientation。
- 悬停界面保留原视图和应用会话，通过独立全屏不透明 Activity 持有手动方向请求；还原、退出、锁屏或方向页离开前台后结束。
- 增加实际屏幕方向确认，成功前显示“旋转中”；按默认显示区原生模式与旋转值确认；5 秒内未确认则提示并撤回，不再仅凭 API 返回就显示成功。
- 增加方向兼容覆盖的应用级 opt-out 属性。增加 15 项原生屏幕方向断言；八组共 4726 项逻辑断言及编译／签名检查通过，尚待 Find N2 真机确认。

## 0.6.1 — 2026-10-26（本地中间构建）

- 修复普通点击应用会带起另一个记住的应用：单开只启动所选分区，不自动读取并启动搭配。
- 双开模式只由“双开”或“游戏双开”明确开启，本次界面结束后不自动恢复；组合模式中仍可分别更换应用。
- 自动进入悬停只承接当前应用。移除默认开启的双开设置开关，旧值继续留存也不会触发搭配。

## 0.6.0 — 2026-10-26（本地测试版）

- 取消半展开自动横屏请求与设置开关；在目录、播放页、双开工具栏和设置页加入“横屏／还原”手动按键，不保留上次手动方向。
- 上半区左右滑动一次切换一个视频应用，先取消目标应用当前触摸序列，再在松手后提交切换；保留竖向及多指操作。下半区游戏会话保留。
- 加入带方向的拖动、滑出和淡入切换动画；目录上方常用卡片也按一次一张吸附翻页。
- 从 GitHub 选用 QmDeve/AndroidLiquidGlassView 的 MIT 原始 AGSL 着色器，固定提交与哈希，完成原生按钮、卡片、权限入口、开关及触控区适配。
- 使用共享 RenderNode 背景采样、原始折射／色散、模糊、高光及按压回弹；低版本或着色器失败时回退。完整许可证随 APK 打包。
- 新增 26 项手势断言；七组共 4711 项逻辑断言通过。新界面、手势与手动方向仍待 Find N2 真机验证；未更新 GitHub Release。

## 0.5.1 — 2026-10-26（本地修正版）

- 针对系统自动旋转开关被关闭、横屏后又恢复原方向的反馈，移除全局旋转锁定和定时续租，改为对当前悬停窗口请求横屏。
- 悬浮窗通过 WindowManager.LayoutParams.screenOrientation 请求方向，主界面通过 Activity 窗口请求；退出只撤回本窗口请求。
- 删除旧的物理旋转 Binder 接口；Shizuku 服务版本升为 8，仅在存在 0.5.0 日志时尝试一次遗留状态恢复。
- 删除 POST_NOTIFICATIONS 声明与授权弹窗，Android 13+ 前台监测通知不在通知栏展示；继续保留后台监测和系统后台活动列表。
- 新增 55 项窗口方向、幂等进入／退出、窗口丢失和独立窗口生命周期断言；六组共 4685 项断言通过。
- 当前未连接手机，旋转和通知实际表现仍待 Find N2 复测。

## 0.5.0 — 2026-10-26（本地测试版）

- 新增视频、游戏双开，默认视频在上半区、游戏在下半区，两个显示与触控会话相互独立。
- 四宫格目录新增游戏分区、“双开”入口，记住上次成功打开的搭配；双开右下角工具栏支持选择、返回与单屏。
- 110°–140°保持 3 秒进入时临时锁定横屏，退出时恢复原旋转模式；增加开关、Binder 死亡恢复、短期租约与恢复日志。
- 更换其中一个应用、打开目录或设置不重建另一应用的显示会话；旧会话的延迟释放不会关闭替代会话。
- 去除播放页不再需要的后台进度轮询，避免与游戏触控竞争；不再读取游戏进度控件。
- 新增 27 项分类、分区与旋转规则断言、2515 项双会话生命周期断言。
- 当前未连接手机，双开、游戏兼容性、自动横屏及恢复尚待真机验证；续播问题仍未解决，未更新 GitHub Release。

## 0.4.0 — 2026-10-25（本地测试版）

- 目录移除顶部应用标题与角度说明，删除分类、列表标题和搜索栏。
- 下半屏应用目录改为每页 2×2 卡片，超过四个可左右翻页。
- 播放页删除独立进度条、校准入口与触控区中央箭头文字，保留无文字触控区。
- 设置按钮统一移至下半屏右侧，关闭／返回入口放在左侧。
- 以同风格半透明圆角面板替换系统设置弹窗，提供开关、角度规则、权限状态和重启监测。
- 打开设置保留上方应用实例及尺寸，返回恢复原下半屏。
- 新界面尚未进行真机视觉和手势验证，续播问题未宣称修复；未自动更新 GitHub Release。
