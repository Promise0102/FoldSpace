# FoldSpace · 折境空间

折叠屏半展开时，将应用放在上半屏，下半屏提供视频进度和手势控制的独立 Android 实验应用。

当前版本 **0.3.1（测试版）**，包名 `com.mkf.foldspace`。主要在 OPPO Find N2 / Android 16 / ColorOS 16.0.5 上验证，需要用户启动并授权 **Shizuku**，无需 Root。

> 已知问题：抖音在全屏与上半屏之间切换后，同一条视频仍可能从头播放。本版已尝试保留任务与恢复进度，真机反馈尚未解决；请勿将其视为无缝续播版本。

## 功能

- 铰链角度处于 **110°–140°（含边界）连续 3 秒**时自动进入；范围外连续 3 秒自动退出。跨越边界重新计时。
- 自动进入时优先接入物理屏幕上的前台应用，退出时尝试将任务放回原屏幕；桌面、系统界面及本应用显示视频目录。
- 手动目录仅列出识别为视频的已安装应用，支持搜索和最近使用。
- 视频应用下半屏提供进度、校准按钮及触控区；抖音可通过下半屏上下滑动切换视频。
- 上半屏进入应用、切换应用和返回目录时使用淡入与轻微位移；下半屏控制区保持位置。
- 沉浸全屏显示，支持系统边缘手势临时唤出系统栏。

这是独立实现，不包含 OPPO 官方软件的代码或资源，也不修改抖音、哔哩哔哩等目标应用。没有实现视频与评论的原生上下屏重排。

## 安装与使用

1. 在仓库的 **Releases** 页面下载安装签名 APK。
2. 安装并启动 [Shizuku](https://shizuku.rikka.app/)，授权折境空间。
3. 打开折境空间，在设置中开启自动悬停并允许悬浮窗。
4. 在正在使用的应用中，将手机保持在 110°–140°约 3 秒，等待自动接入上半屏；完全展开等范围外位置保持 3 秒退出。

也可以在折境空间目录中点击视频应用。下半屏“返回”轻点向上方应用发送返回，长按回到视频目录。进度不可用时，可以先显示目标视频的原生进度条，点击“校准进度条”，依次点原生进度条左右两端。直播、广告及没有可操作进度的内容不保证支持。

更新后打开一次折境空间；若此前已开启自动悬停，会恢复监测服务。系统强行停止应用、限制后台服务或停止 Shizuku 后，需要重新启动相应服务。

## 构建

Windows + PowerShell 7、JDK 17 或更高版本、Android SDK。无需 Gradle。SDK 需要 Build Tools **36.0.0** 及 Android **API 37** 平台；脚本兼容平台目录 `android-37` 和 `android-37.0`。

设置 `JAVA_HOME` 和 `ANDROID_HOME`（或 `ANDROID_SDK_ROOT`），然后在项目根目录执行：

```powershell
pwsh -File ./scripts/Test-FoldSpaceControls.ps1
pwsh -File ./scripts/Build-FoldSpace.ps1
```

构建时核对 `foldspace/libs/dependencies.json` 中固定的依赖哈希。首次本地构建会在忽略提交的 `signing/` 中生成自己的签名密钥，APK 输出到 `output/`。请妥善保留密钥；自行生成的签名不能直接覆盖 Releases 中使用其他证书签名的安装包。

已有同名安装包时脚本拒绝覆盖。需要在其他目录构建可使用：

```powershell
pwsh -File ./scripts/Build-FoldSpace.ps1 -OutputDirectory ./build-output
```

可通过 `-BuildToolsVersion`、`-AndroidPlatform` 参数指定本机 SDK 版本。`-Version` 必须与源码 Manifest 一致。

## 验证与限制

自动检查包括 46 项折叠范围及持续计时断言、2041 项进度坐标断言、15 项播放恢复条件断言。已完成资源 / Java / DEX 编译、签名和 ZIP 对齐检查。

Find N2 真机确认了上半屏显示抖音、视频目录、自动进入与退出、现有任务移动。进度接续测试未通过，其他折叠设备、全部视频内容及长时间后台运行尚未全面验证。详见 [验证记录](docs/VALIDATION.md) 和 [更新记录](docs/CHANGELOG.md)。

目标应用可能在显示区、屏幕尺寸或其他配置变化时重建页面。Shizuku 授权不保证目标应用保留播放状态，也不能让未提供进度的内容自动支持跳转。

## 权限与数据

- 悬浮窗用于半展开界面，前台服务和通知用于持续监听铰链传感器。
- Shizuku 用户服务以 shell 权限创建临时显示区、移动应用任务，并向目标应用传递触摸、返回和进度操作。
- 应用不申请联网权限。最近使用与校准数据保存在本地；技术诊断仅保存在应用自己的外部文件目录。
- 仓库不包含签名私钥、设备日志、用户截图、原始厂商 APK 或反编译产物。
